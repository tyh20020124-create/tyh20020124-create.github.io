# Breatho web assets

These are optimised web derivatives made from the published DIS/SIGGRAPH project materials. Original source files remain in `E:\作品集\作品素材\breatho\dis26`.

- `prototype-hero.webp` — white-background final prototype; use as primary hero image.
- `prototype-dark.webp` — dark-background product image; use for the closing or product-detail section.
- `interaction-overview.webp` — concept and wearing-context strip.
- `wearable-concept.webp` — belt, air chambers, controller, and body placement diagram.
- `airbag-closeup.webp` — close view of the chamber against the abdomen.
- `airbag-fitting.webp` — fitting and placement study.
- `treadmill-test.webp` — prototype worn during treadmill testing.
- `breathing-without.webp` — irregular respiratory trace without guidance.
- `breathing-with.webp` — more periodic respiratory trace with guidance.

Do not add questionnaire exports, participant identity files, raw study data, or internal debugging screenshots to the public website.
